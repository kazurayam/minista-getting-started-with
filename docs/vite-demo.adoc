開発サーバーを立ち上げるにはこうする。

[source,shell]
----
$ cd $ROOT/vite-demo
$ bun install
$ bun run dev
----

開発サーバが立ち上がったらブラウザで http://localhost:5173 を開け。viteのdemoの画面が見えるはず。

image:{PAGES_URL}/images/001-vite-demo.png[]
